# Provider response fixtures

Hand-written payloads shaped like each official SDK's `model_dump(mode="json")` output
(OpenAI Responses API, Anthropic Messages API, Gemini `generate_content`). Token values
are illustrative, partly taken from the providers' documented examples (Anthropic cache
and compaction examples, OpenAI reasoning example, Gemini total-token definition).
They are **test fixtures**, not observed usage.
